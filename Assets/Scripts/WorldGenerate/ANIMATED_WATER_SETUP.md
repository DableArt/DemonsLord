# Настройка анимированной воды (AnimatedTile)

## Обзор архитектуры слоёв

Каждый чанк имеет два Tilemap-слоя:

| Слой | Sorting Order | Назначение |
|------|--------------|------------|
| `Water` | 0 | Вода — рисуется **ниже** всего |
| `Ground` | 1 | Земля и берег — рисуется **поверх** воды |

Анимированный тайл воды кладётся как на чисто водные клетки, так и **под береговые тайлы**
(`Ground` слой, `sortingOrder = 1`). Это позволяет анимации воды просвечивать
через полупрозрачные/прозрачные края берегового спрайта.

---

## Шаг 1 — Создание AnimatedTile

1. В **Project Browser** нажмите правой кнопкой → **Create → 2D → Tiles → Animated Tile**.  
   Если пункт не виден, убедитесь, что установлен пакет **2D Tilemap Extras**
   (`Window → Package Manager → 2D Tilemap Extras`).
2. Назовите ассет, например `WaterAnimated`.
3. Откройте тайл в инспекторе:

| Поле | Значение |
|------|---------|
| **Number of Animated Sprites** | `4` (количество кадров анимации) |
| **Animated Sprites [0..3]** | Спрайты кадров воды по порядку |
| **Minimum Speed** / **Maximum Speed** | Скорость (кадров/сек), например `4` / `4` для равномерной анимации |
| **Start Time** | `0` |
| **Collider Type** | `None` (коллизия обрабатывается отдельно) |

---

## Шаг 2 — Назначение в WorldSettings

1. Найдите ScriptableObject-ассет **WorldSettings** в Project Browser.
2. В разделе **Tiles — Water** → поле **Water Tiles**:
   - Задайте **Size = 1** (или больше, если планируете несколько вариантов).
   - В **Element 0** перетащите `WaterAnimated`.

> `waterTiles[0]` — основной тайл воды; остальные элементы зарезервированы
> для будущих вариантов (глубокая вода, лава и т.п.).

---

## Шаг 3 — Береговые тайлы (ShoreConfig)

Берег теперь поддерживает **направленные тайлы** — отдельный спрайт для каждой стороны, с которой примыкает вода.

### 3.1 Структура ShoreConfig

В WorldSettings → раздел **Tiles — Ground** → поле **Shore Tiles** содержит группу полей:

| Поле | Когда применяется |
|------|-------------------|
| **Top** | Вода сверху (y+1) |
| **Bottom** | Вода снизу (y-1) |
| **Left** | Вода слева (x-1) |
| **Right** | Вода справа (x+1) |
| **Top Left** | Вода только по диагонали сверху-слева |
| **Top Right** | Вода только по диагонали сверху-справа |
| **Bottom Left** | Вода только по диагонали снизу-слева |
| **Bottom Right** | Вода только по диагонали снизу-справа |
| **Fallback** | Несколько сторон воды сразу или конкретный тайл не назначен |

### 3.2 Алгоритм выбора тайла

1. Если у клетки **ровно одна** кардинальная сторона с водой → берётся соответствующий тайл (`top` / `bottom` / `left` / `right`).
2. Если кардинальных нет, но **ровно одна** диагональ с водой → берётся диагональный тайл.
3. Иначе (несколько сторон, или тайл не назначен) → берётся `fallback`, затем `groundTiles[0]`.

### 3.3 Назначение в инспекторе

1. Подготовьте спрайты переходов для нужных направлений — каждый должен быть **частично прозрачным** по стороне, смотрящей в воду, чтобы AnimatedTile просвечивал снизу.
2. Создайте обычный Tile (**Create → 2D → Tiles → Tile**) для каждого направления.
3. В WorldSettings → **Tiles — Ground** → **Shore Tiles** назначьте тайлы в поля `top`, `bottom`, `left`, `right` и т.д.
4. Поле **Fallback** — минимально необходимый тайл; остальные поля опциональны.

> Если поле `Fallback` не задано, берег отображается с помощью `groundTiles[0]`.

> Для полностью автоматической береговой линии можно назначить **RuleTile** в поле `Fallback` — он сам разберётся с соседями средствами Unity.

---

## Шаг 4 — Расширение палитры

- **Несколько вариантов земли:** добавьте тайлы в массив **Ground Tiles**.  
  `WorldSettings.GetGroundTile()` сейчас возвращает `groundTiles[0]`; при необходимости
  рандомизации добавьте свою логику в `Chunk.Render()`.

- **Несколько вариантов воды:** добавьте AnimatedTile в массив **Water Tiles**.  
  `WorldSettings.GetWaterTile()` возвращает `waterTiles[0]`; для разных биомов
  можно расширить метод.

- **Направленные береговые тайлы:** назначьте отдельные спрайты в поля `top`, `bottom`,
  `left`, `right` (и диагонали) структуры **Shore Tiles**.  
  Поле `Fallback` используется для любых комбинаций, не покрытых направленными тайлами.

- **RuleTile для берега:** создайте RuleTile и назначьте его в поле **Fallback** структуры
  **Shore Tiles**. RuleTile автоматически выберет правильный спрайт по соседям,
  что исключает ручной подбор вариантов.

---

## Совместимость с shader-подходом

Текущая архитектура намеренно не привязана жёстко к AnimatedTile:

- Поле `waterTiles` имеет тип `TileBase[]` — принимает любой тип тайла.
- В будущем можно создать кастомный `ShaderAnimatedTile : TileBase`
  и просто заменить `waterTiles[0]`, не меняя остальной код.
- Слой `Water` (sortingOrder = 0) уже изолирован — шейдерный материал
  можно назначить прямо на его `TilemapRenderer`.
